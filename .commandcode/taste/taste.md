# Taste

- Commit messages: imperative mood, short subjects under 60 characters, no emojis, no filler, and no `Co-authored-by` trailers or AI attribution. Confidence: 0.7
- Testing: don't declare untested code out of scope or "deferred" — write the tests. Pushing back on a deferred test gap is treated as a correction, not a new request. Confidence: 0.6
- Code comments: add them only where genuinely necessary, and make them explain WHY (trade-offs, invariants, non-obvious constraints) rather than WHAT the code does. No verbose docblocks on self-explanatory functions. Confidence: 0.7
